1. Fix Invalid Date in Account Timeline and everywhere in AccountDetail.jsx:
The timestamps from account_events are stored as TEXT in PostgreSQL. 
In AccountDetail.jsx find the date formatting function and replace it with:
const fmt = (ts) => {
  if (!ts) return '—';
  const n = Number(ts);
  if (isNaN(n)) return ts;
  const d = new Date(n > 9999999999 ? n : n * 1000);
  return isNaN(d.getTime()) ? String(ts) : d.toLocaleString('en-GB');
};
