The main problems:
1. column "tenant_id" does not exist in events table
2. All db.all() and db.get() calls return {rows: [...]} in PostgreSQL but code expects plain arrays

Fix ALL files in server/routes/ (events.js, overview.js, anomalies.js, visitor.js, clusters.js, upload.js, ingest.js, webhook.js, accounts.js, verdict.js):
- Every db.all() result: use const result = await db.all(q); const rows = Array.isArray(result) ? result : (result.rows || []);
