Build a fraud detection dashboard web app for SaaS companies using Fingerprint Pro data.

TECH STACK:
- React frontend (single page)
- Node.js/Express backend
- SQLite database (file-based, no setup needed)
- File upload for JSON data ingestion

CORE FEATURES:

1. FILE UPLOAD - Accept JSON array or newline-delimited JSON objects. Parse and store all events in SQLite. Fields to extract: event_id, timestamp, visitor_id, visitor_found, first_seen_at, last_seen_at, ip_address, browser_name, os, device, bot, suspect_score, tampering, tampering_ml_score, anti_detect_browser (from tampering_details), anomaly_score (from tampering_details), vpn, proxy, incognito, virtual_machine, virtual_machine_ml_score, city_name, country_code, asn_name, velocity_distinct_ip_24h, velocity_events_24h, font_hash (from raw_device_attributes), webgl_renderer_unmasked (from raw_device_attributes.webgl_basics), hardware_concurrency, device_memory, platform, confidence_score

2. RISK SCORING ENGINE - Calculate composite risk score 0-100 per event:
- anti_detect_browser=true → +40
- tampering_ml_score > 0.5 → +25
- tampering_ml_score 0.2-0.5 → +15
- virtual_machine=true → +20
- anomaly_score > 0 → +15
- vpn=true → +10
- proxy=true → +10
- suspect_score > 10 → +10
- velocity_distinct_ip_24h > 3 → +15
- visitor_found=false → +5
Risk levels: 0-20 CLEAN (green), 21-40 LOW (yellow), 41-65 SUSPICIOUS (orange), 66+ HIGH RISK (red)

3. CROSS-VISITOR ANOMALY DETECTION:
a) IP Sharing: visitor_ids sharing same IP
b) Font Hash Clustering: same font_hash across many visitors
c) WebGL Clustering: same webgl_renderer_unmasked across visitors
d) Rapid IP Change: same visitor_id with 2+ IPs within 10 minutes
e) VM + MacIntel contradiction: virtual_machine=true AND platform=MacIntel AND renderer contains Apple M
f) Anti-detect cluster: group anti_detect_browser=true events by font_hash or webgl_renderer

4. DASHBOARD VIEWS:

A) OVERVIEW PAGE - 4 metric cards (Total Events, High Risk %, Suspicious Visitors, Anomalies Found), events table with columns: Timestamp, Visitor ID, City, OS/Device, Risk Score badge, Flags icons (VPN/Proxy/VM/AntiDetect/Tampering/Bot). Filters by risk level, country, flag type. Click row opens Visitor Detail.

B) VISITOR DETAIL PAGE - All events for visitor_id chronologically, device fingerprint summary (OS/Browser/GPU/Screen/Platform/Font Hash/Hardware/Memory), risk timeline chart, related visitors sharing same IP or font_hash or webgl_renderer, all flags with plain English explanation.

C) ANOMALIES PAGE - All detected anomalies grouped by type, each with affected visitor_ids, severity, plain English explanation.

D) CLUSTERS PAGE - Visual grouping by font_hash, webgl_renderer, IP address. Table showing cluster size, shared value, risk levels.

5. UI: Clean minimal professional (like Linear or Stripe). Dark sidebar. Color coding: red HIGH RISK, orange SUSPICIOUS, yellow LOW, green CLEAN. Responsive.
